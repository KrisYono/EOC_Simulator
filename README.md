# EOC Simulator

Emergency Operations Centre (EOC) serious-game simulator created for the **Justice Institute of British Columbia (JIBC)** through the Centre for Digital Media (CDM) Spring 2025 industry program.

## My role

Unity gameplay / systems engineering on the industry team — simulation flows, interactions, and project integration for JIBC’s training context.

## Highlights

- Serious-game EOC training scenario
- Industry partner: JIBC (via CDM)
- Unity project packaged under `EOC_Simulator/`

## Technology

- Unity (project under `EOC_Simulator/`)
- C#

## Open the project

1. Install a Unity version compatible with the project’s `ProjectSettings/ProjectVersion.txt`.
2. Clone this repository.
3. Add the nested folder `EOC_Simulator/` as a Unity project in Unity Hub.
4. Open the main scene from that project’s `Assets` folder.
